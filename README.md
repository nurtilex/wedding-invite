# Онлайн-пригласительное на свадьбу

SPA на React + Vite + TypeScript. Три экрана подряд:

1. **Обложка** — имена, дата, фото `image_one.jpeg` фоном.
2. **Приглашение** — монограмма из инициалов, обращение к гостям, площадка,
   сбор гостей и начало торжества, кнопки маршрута. Фон — `image_intro.jpeg`.
3. **Футер** — монограмма и прощание.

Фоновая музыка, языки — кыргызский (по умолчанию) и русский.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # посмотреть собранную версию
```

## Что менять

**Все данные — в одном файле: [`src/config.ts`](src/config.ts).**

| Поле | Что это |
| --- | --- |
| `groom`, `bride` | имена молодожёнов (отдельно на кырг. и рус.) |
| `date` | дата и время: `{ year, month, day, hour, minute }` |
| `gathering` | время сбора гостей; `null` — колонка не показывается |
| `venue.name`, `venue.address` | название площадки и адрес |
| `coverPhoto`, `invitePhoto` | фото-фоны первой и второй страниц; пустая строка — без фото |
| `coords` | координаты — из них собираются ссылки на карты |
| `mapLinks` | необязательно: готовые ссылки из «Поделиться» в 2ГИС / Google Maps |
| `music.src` | путь к аудиофайлу (см. `public/music/README.txt`) |
| `defaultLang` | язык по умолчанию: `'kg'` или `'ru'` |
| `monogram` | инициалы в кружке внизу страницы |

Длинное обращение к гостям на второй странице — `inviteLong` в словаре.
Остальные тексты («Урматтуу коноктор», «Как добраться» и т.д.) — в [`src/i18n.ts`](src/i18n.ts),
словарь `dict`. Там же названия месяцев: по умолчанию современные (`сентябрь`),
рядом закомментирован традиционный кыргызский набор (`аяк оона`).

Цвета и шрифты — переменные в начале [`src/styles.css`](src/styles.css).

## Язык

- По умолчанию открывается кыргызская версия.
- Гость переключает кнопкой в правом верхнем углу, выбор запоминается в браузере.
- Язык можно зафиксировать в ссылке: `?lang=ru` или `?lang=kg`.
  Параметр в ссылке важнее сохранённого выбора — удобно рассылать
  русскоязычным гостям сразу `.../?lang=ru`.

## Музыка

Сейчас стоит фрагмент **Lana Del Rey — «Young and Beautiful»**, отрезок **0:10 – 1:40**:
вступление со струнными → первый куплет → припев → спад во втором куплете.
90 секунд, 1.4 МБ, −18 LUFS, с плавными входом и выходом, чтобы петля не щёлкала на стыке.

Полный трек лежит в `music-source/` — папка вне `public/`, в сборку не попадает.
Оттуда же можно вырезать другой фрагмент:

```bash
./scripts/prepare-music.sh music-source/young-and-beautiful-full.mp3 1:55 90   # второй припев
./scripts/prepare-music.sh ~/Downloads/другой-трек.mp3                          # первые 90 секунд
```

Скрипт обрезает фрагмент, выравнивает громкость двухпроходным `loudnorm`, вешает фейды
и кладёт результат в `public/music/wedding.mp3`. Нужен `ffmpeg` (`brew install ffmpeg`).

Автоплей со звуком браузеры блокируют, поэтому музыка стартует при первом касании экрана
(`music.startOnFirstTap: true`). Поставьте `false` — будет включаться только по кнопке.
Если файла по указанному пути нет, кнопка не показывается.

Подпись о треке внизу страницы — `music.credit` в конфиге. Пустая строка в `text` уберёт её.

## Карты

Кнопки открывают 2ГИС и Google Maps во внешнем приложении (на телефоне — в
нативном). Ссылки собираются из `coords`. Надёжнее взять готовые ссылки:
откройте площадку в 2ГИС / Google Maps → «Поделиться» → вставьте в `mapLinks`.

## Публикация

`npm run build` даёт статический `dist/` — его можно залить куда угодно:

- **Netlify / Vercel / Cloudflare Pages** — перетащить папку `dist` или
  подключить репозиторий (build: `npm run build`, output: `dist`).
- **GitHub Pages** — залить `dist`, но добавить в `vite.config.ts`
  `base: '/имя-репозитория/'`.

Превью ссылки в WhatsApp/Telegram берётся из og-тегов в `index.html`.
Положите картинку `public/og.jpg` (1200×630) — тогда ссылка будет с картинкой.
